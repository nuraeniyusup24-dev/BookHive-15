# BookHive

Aplikasi library system untuk pengelolaan peminjaman dan pengembalian buku adalah sebuah sistem informasi yang dirancang untuk membantu perpustakaan dalam mengelola seluruh aktivitas terkait koleksi buku dan transaksi pengguna secara lebih efektif dan efisien.

Sistem ini memungkinkan petugas perpustakaan untuk melakukan pendataan buku, mulai dari penambahan koleksi, pengelompokan berdasarkan kategori, hingga pencatatan detail seperti judul, penulis, penerbit, dan jumlah stok. Selain itu, aplikasi ini juga menyediakan fitur manajemen anggota, di mana data peminjam seperti nama, alamat, dan kontak dapat tersimpan dengan rapi dalam database.

Pada proses peminjaman, sistem akan mencatat buku yang dipinjam oleh anggota beserta tanggal peminjaman dan batas waktu pengembalian. Hal ini memudahkan dalam pemantauan status buku, apakah masih tersedia atau sedang dipinjam. Sedangkan pada proses pengembalian, sistem akan secara otomatis memperbarui stok buku dan dapat menghitung denda apabila terjadi keterlambatan pengembalian.

Aplikasi ini juga biasanya dilengkapi dengan fitur pencarian buku, laporan transaksi (peminjaman dan pengembalian), serta notifikasi untuk mengingatkan batas waktu pengembalian. Dengan adanya sistem ini, pengelolaan perpustakaan menjadi lebih terstruktur, mengurangi kesalahan pencatatan manual, serta meningkatkan pelayanan kepada pengguna.
